# 🌿 BioDINO-Edge & Academic Portfolio Web Application

Production-grade Next.js 16 (App Router + Turbopack + Tailwind CSS v4) static export site showcasing:
1. **Academic Portfolio & Scholastic Highlights (`/`):** Full academic credentials, rank 1 GPA distinction (19.00/20.00), coursework transcripts, TA experience with verification letters, and prospective advisor outreach.
2. **BioDINO-Edge Research Paper Page (`/research/biodino-edge/`):** Scientific showcase with dual-foundation manifold (DINOv2 + BioCLIP), analytical Ledoit-Wolf shrinkage, zoomable interactive figures, and BibTeX citation.
3. **BioDINO-Edge Android Edge Showcase (`/projects/biodino-edge-android/`):** 100% offline edge scanner built with Kotlin 2.0, Jetpack Compose, ONNX Runtime Mobile NNAPI, and 22.7 MB standalone footprint.

---

## 🛠️ Quick Commands

```bash
# 1. Install dependencies
npm install

# 2. Run local development server (http://localhost:3000)
npm run dev

# 3. Compile static export (generates web/out/)
npm run build
```
